# 108 STUDIO v0.4.5

## 変更点
- 「＋ ページを追加」から表紙、ミーム扉、自曲扉、企画ページを選択して追加
- ページ一覧で選択・上下移動・削除
- 表紙と扉のテキストをプレビュー上で直接編集
- 扉の区切りに応じたミーム／自曲の配色（ミーム＝ピンク、自曲＝グループカラー）
- 既存ブラウザ保存データを初回読み込み時にページ一覧へ変換
- 企画取り込み時は表紙・カテゴリ扉を自動生成。後から自由に変更可能
- Noto Sans JP、ログイン、PDF印刷、サムネイル機能は維持

## 更新方法
ZIPを解凍して同名ファイルをGitHubに上書き。Renderの環境変数変更は不要。

注意: ページ構成はブラウザのローカルストレージに保存されます。ブラウザや端末を変えると引き継がれません。
