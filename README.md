# 108 STUDIO v0.3

v0.2.1のテキスト・PDF取り込みとGoogleログインを維持し、CUTIE STREETの撮影案PDFを参考に企画ページを再設計。

- ミーム企画: ピンク背景、ピンク見出し
- 自曲企画 / ミーム × 自曲 / 楽曲企画: グループカラー背景、黒見出し
- グループカラー: 画面左下のカラーピッカーで変更
- 表紙・カテゴリ扉: オン/オフ可能
- 参考動画サムネイル: 企画編集の「参考動画サムネイル」欄に画像の直接URLを入力（TikTok動画URLからの自動取得は未対応）
- 各企画の本文は元の文章を保持。相談内容・評価は取り込み対象外

## 更新
ZIP内の server.py, requirements.txt, render.yaml, README.md と static/index.html を同じディレクトリ構造でGitHubに上書きしてください。Renderの環境変数の変更は不要です。

## 制約
Canvaファイルを直接インポートする機能ではなく、提供されたPDFのレイアウトを参考に再現したものです。長文はプレビューで文字あふれ警告が出るため補足ページを利用してください。既存データはv0.2のローカル保存キーを引き継ぎます。
