# 108 STUDIO v0.4.2

v0.4.1からの更新。Googleログイン・既存の一括取り込み・PDF抽出・セザンヌフォントファイル読み込み機能は維持。

- 一括取り込み後、TikTokの公開動画サムネイルを自動取得（TikTok oEmbed API。取得できない場合は手動画像設定）
- Canvaに合わせ「企画内容 → 撮影／演出イメージ → 狙い／ポイント」の順番に統一
- 人選理由は狙い／ポイントの末尾に【人選理由】として原文を保持（勝手に改稿しない）
- 本文フォントサイズ・行間・余白を調整
- 企画名、撮影／演出イメージ、サムネイルの未入力を警告

注意：元データに企画名・撮影イメージがない場合、自動創作しません。提出前に入力してください。
セザンヌは利用許諾されたフォントファイルをブラウザで選択した場合のみ確実に適用されます。フォントファイルは配布物に含みません。

GitHubのリポジトリルートへ ZIP内の5ファイルを上書きアップロード。Render環境変数の変更不要。
