# 108 STUDIO v0.4.1 — セザンヌ対応

v0.4のサムネイル取得、一括企画取り込み、Googleログインを維持。

## 変更点
- 資料ページと操作画面のフォント優先順位をセザンヌに変更。
- ライセンス上Web利用が認められるセザンヌのフォントファイルをブラウザから読み込む機能を追加。読み込むとPDF印刷にも反映。
- フォントファイルは配布物に含めず、サーバーにアップロードもしません。

## 注意
- フォント名だけの指定では、端末にフォントがない場合は代替フォントになります。正確な再現には適切なライセンスを持つフォントファイルを指定してください。
- ページを再読み込みするとフォントファイルの再指定が必要です。
- セザンヌのウェブ埋め込みやPDF利用については契約条件を確認してください。

## 更新
ZIPを解凍し、既存ファイルと同じ階層でGitHubへ上書き。Render環境変数は変更不要。
