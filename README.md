108 STUDIO v0.4.9

v0.4.8 UIを維持し、参考動画のサムネイル枠をクリックしてスクショ画像を選択できるようにしました。枠をフォーカスしてCmd+V/Ctrl+Vでクリップボード画像を貼り付けできます。画像はブラウザ内で縮小・JPEG圧縮して保存し、位置・拡大率を調整できます。参考動画URLリンクは維持します。

GitHubへZIP内ファイルを上書きしてください。Render環境変数の変更は不要です。画像はブラウザのlocalStorageに保存されるため、大量の画像や別端末への同期には対応しません。


v0.4.10: サムネイル枠の下に常時表示される『スクショを選択』ボタンを追加。OS標準のファイル選択を使用し、画像読み込みのブラウザ互換性も改善。
